# هبة خالد الزين — سيرة ذاتية ومعرض أعمال

مشروع جامعي متكامل بواجهة عربية، مبني باستخدام **HTML وCSS وJavaScript** فقط، دون إطار عمل أو مكتبات تشغيل خارجية.

## التشغيل

افتح ملف `index.html` مباشرة في متصفح حديث. الصور والخطوط موجودة داخل المشروع، لذلك تعمل الصفحة دون اتصال بالإنترنت.

للتشغيل عبر خادم محلي عند توفر Node.js:

```sh
npm start
```

ثم افتح `http://127.0.0.1:4173`.

لا تحتاج إلى `npm install` لعرض المشروع. التثبيت مطلوب فقط لتشغيل أدوات الاختبار الاختيارية.

## الميزات

- تصميم متجاوب مع الهاتف واللوحي والحاسوب، وقائمة تنقل جانبية تتحوّل إلى قائمة للهاتف.
- واجهة عربية RTL وإنجليزية LTR، مع حفظ اختيار اللغة.
- وضع فاتح وداكن، مع حفظ الاختيار محليًا.
- نبذة شخصية، مهارات وأدوات، ورحلة تعلّم مقترحة.
- أربعة مشاريع تصوّرية: Studyflow وInsight وForma وRiwaq.
- خمس صور مولّدة: صورة رئيسية وأربع صور للمشاريع، محسّنة بصيغة WebP.
- تصفية المشاريع حسب النوع، ونافذة تفاصيل تدعم لوحة المفاتيح ومفتاح Escape.
- حفظ السيرة الذاتية بصيغة PDF من نافذة الطباعة، بتنسيق مستقل مناسب لورق A4.
- التحقق من حقول التواصل وتجهيز رسالة يمكن نسخها أو فتحها في تطبيق البريد.
- نسخ البريد، تنقّل سلس، تحديد القسم الحالي، وحالات تركيز واضحة.
- دعم تفضيل تقليل الحركة، ونصوص بديلة للصور.
- خطوط محلية مرخّصة برخصة SIL Open Font License.

## تعديل البيانات

1. افتح `script.js` وعدّل `CV_PROFILE` للاسم والتخصص والموقع والبريد.
2. عدّل `PROJECTS` لبيانات المشاريع باللغتين. يحتوي كل مشروع على الاسم والوصف والميزات والتقنيات والصورة.
3. عدّل `COPY.ar` و`COPY.en` للنبذة ونصوص الصفحة. بعض النصوص تتضمّن الاسم الأول، فعدّلها مع بياناتك.
4. لتغيير الألوان، عدّل المتغيّرات في بداية `styles.css`.
5. لتبديل الصور، ضع صورك في `assets/images` مع المحافظة على الأسماء أو تعديل المسارات.

## التحقق الاختياري

```sh
npm install
npm start
```

وفي طرفية أخرى:

```sh
npm test
```

تحتاج الاختبارات إلى Microsoft Edge وNode.js 18 أو أحدث. تستخدم Playwright كأداة تطوير فقط. تختبر التصفية والتفاصيل واللغة والثيم والتحقق من النموذج والطباعة والتجاوب وتحميل الصور، ثم تنتج لقطات ونسخة PDF.

## ملاحظات لتقديم المشروع

الاسم المعتمد هو **هبة خالد الزين**. النبذة والمهارات والأعمال **محتوى توضيحي قابل للتعديل**. المشاريع الأربعة أفكار عرض، ولا تتضمن هذه الحزمة تطبيقاتها الفعلية أو خادمًا خلفيًا. صور المعرض مولّدة بالذكاء الاصطناعي.

البريد `hiba.khaled.alzein@example.com` عنوان تجريبي. نموذج التواصل يجهّز الرسالة محليًا؛ زر فتح البريد يمرّرها إلى برنامج البريد ولا يرسلها تلقائيًا. ضع بريدًا حقيقيًا في `CV_PROFILE` قبل الاستخدام الشخصي.

لتحميل السيرة من داخل الصفحة، اضغط «تحميل CV» ثم اختر «حفظ بتنسيق PDF». استخدم النسخة الجاهزة داخل `artifacts` عند الحاجة.
