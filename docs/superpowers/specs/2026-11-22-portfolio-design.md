# Developer portfolio design

The user requests HTML/CSS/JS, a modern distinctive CV, an authored biography and software projects, generated gallery images, and an image of the complete result for university submission. The user delegated the content after selecting software developer.

Implementation choice: a buildless, locally runnable single-page site. A framework would add installation without improving this deliverable. A static mockup would omit the requested JavaScript interactions. Personal facts and project implementations are illustrative and labeled.

## Direction contract
THESIS: A personal software studio; bold Arabic type meets tangible project mockups. Work and personal introduction lead, rather than fabricated career claims.
OWN-WORLD: White and pale lavender, saturated iris purple, ink text, Alexandria Arabic typography, Manrope Latin typography, restrained line icons. A persistent white right rail forms the signature layout.
STORY: Meet Hiba Khaled Al-Zein, understand her interests, inspect four academic concepts, discover tools and learning journey, prepare a contact message.
FIRST VIEWPORT: Right rail 240px, top utility row, a two-column hero with large right-aligned Arabic headline and generated lavender laptop sculpture on the left. Primary work link and secondary CV action beneath the biography. Start the gallery immediately after the introduction.
FORM: Code-led implementation chosen by the implementer under the user's delegation; no approved image comp exists. Signature interaction is a keyboard-accessible project detail lightbox, with gallery filtering and language/theme persistence. One soft hero entrance, no hidden-on-load page content.
FINISH: Verify desktop/mobile rendering, real controls and offline assets; provide screenshot files and source documentation. Every generated raster retains its exact prompt in assets/image-provenance.json.
